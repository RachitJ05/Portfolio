# Rachit Jain — Developer Portfolio

A React + TypeScript portfolio built with Vite. Includes a persistent dark/light theme toggle, selected projects with GitHub and live-demo links, experience, skills, and contact information.

## Requirements

- Node.js 18+
- npm

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local development URL (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Profile copy and social links: `src/components/Main.tsx`
- Project descriptions, GitHub repositories, and live demos: `src/components/Project.tsx`
- Experience and education: `src/components/Timeline.tsx`
- Skills and achievements: `src/components/Expertise.tsx`
